# Codex 定时发送台（桌面版）

给远端 Codex 会话按计划自动发消息的 Windows 桌面程序。在窗口里选会话、写内容、定时间和周期，到点由程序通过 SSH 执行：

```
codex queue --thread <会话id> --message <内容> --resume
```

效果等同于你在 Codex 界面里手动输入一条消息再回车：消息进入该会话的队列，守护进程把会话重新跑起来。

单文件 exe，除了 Windows 自带的 .NET Framework 4.x 之外不需要安装任何东西，也不需要浏览器。

---

## 启动

- 双击 `CodexScheduler.exe`
- 托盘菜单勾选「开机自启动」后，每次登录会**只在托盘里**启动（`--tray`），不弹窗口
- 关闭窗口只是收进托盘；要真正退出，右键托盘图标 →「退出」
- 程序是**单实例**的：重复双击 exe 只会把已经运行的窗口调出来，不会多开导致重复发送

## 界面

**顶栏**：连接状态、「暂停调度」开关、SSH 主机（回车或点「连接」生效）。

**左侧「选择会话」**：会话列表从远端 `~/.codex/state_5.sqlite` 读取，按最近活跃排序。支持搜索、「只看已选」、全选 / 清空 / 刷新；右键可以复制会话 ID。搜索时已勾选的会话不会丢；已勾选但不在列表里的会话（比如已归档）会以橙色显示。

**右侧三个页面**

| 页面 | 用途 |
|---|---|
| 新建任务 | 任务名称、发送内容（快捷短语可自定义）、周期、结束条件；下方实时显示「下次执行」；底部固定「立即发送一次 / 预览命令 / 保存任务」 |
| 任务列表 | 状态、下次执行倒计时、上次结果；新建 / 立即执行 / 编辑 / 复制 / 暂停启用 / 删除，右键菜单同样可用 |
| 运行日志 | 每次执行的逐会话结果，选中一行在下方直接看完整输出；可「只看失败」 |

周期四种：

- **单次**：指定日期时间（有「+10 分钟」「明早 09:00」等快捷按钮）；错过不超过 6 小时会补发一次，超过就跳过
- **每天**：指定时刻
- **每周**：选星期（有「工作日 / 周末 / 每天」快捷按钮）+ 时刻
- **间隔**：每 N 分钟或 N 小时，可选首次时间

结束条件（单次任务没有）：可设「最多执行 N 次」或「截止日期」，到了就停，不会多发一次。

「立即发送一次」不保存任务，直接把当前内容发给勾选的会话。任务列表里的「立即执行」**不会**改动原定计划。

### 快捷键

| 按键 | 作用 |
|---|---|
| Ctrl+S / Ctrl+Enter | 保存任务（新建任务页） |
| Ctrl+N | 新建任务 |
| Ctrl+1 / 2 / 3 | 切换页面 |
| Ctrl+F | 搜索会话 |
| F5 | 刷新会话列表 |
| 任务列表里 Enter / Delete / 空格 | 编辑 / 删除 / 暂停或启用 |

## 数据文件

都在 exe 同级的 `data` 目录（不可写时退到 `%APPDATA%\CodexScheduler`），可以从「运行日志 → 打开数据目录」直接打开：

| 文件 | 内容 |
|---|---|
| `jobs.json` | 任务定义（每次保存会留一份 `jobs.json.bak`） |
| `jobs.json.broken-*` | jobs.json 读不出来时自动备份的原文件，程序不会再用空列表把它覆盖 |
| `run-log.jsonl` | 每次执行的详细结果 |
| `app.log` | 启动、会话刷新、触发、跳过记录（排查「为什么没发」先看这个；超过 1 MB 自动轮换） |
| `settings.json` | 主机、快捷短语、是否暂停调度 |

## 原理与限制

- 每条任务记住自己的 SSH 主机。切换顶栏主机只影响新建的任务，已有任务仍然发往原主机（编辑保存时会提示是否改到当前主机）。
- 脚本通过 `ssh <主机> "bash -s"` 从标准输入传给远端，消息长度不受 Windows 命令行 8191 字符的限制。
- 程序每 10 秒扫描一次任务；检测到 `jobs.json` 被外部修改会自动重载。
- 到点时程序必须在运行。**电脑关机期间不会执行**，恢复后：周期任务补发一次再按计划继续；单次任务错过 6 小时以内补发，否则跳过。
- 定时触发时如果 **SSH 连不上**（退出码 255），5 分钟后自动重试，最多 3 次；其他失败不重试，避免重复投递。
- 远端账号限流时消息会被吞，日志里会标「限流」，等窗口重置后再执行即可。

## 自检与排错

```powershell
.\CodexScheduler.exe --selftest   # 检查周期计算、截止日期、输入校验、远端连接、数据读写
.\CodexScheduler.exe --layout     # 导出控件坐标，被截断的控件会标 !!CLIPPED（不会触发任何发送）
```

结果写到 `data\selftest.log`、`data\layout.txt`。界面上的意外错误会记到 `app.log`，程序不会直接崩溃。

## 从源码构建

只需要 Windows 自带的 .NET Framework 4.x（`csc.exe`），无需 SDK、NuGet 或联网：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物 `CodexScheduler.exe` 在仓库根目录。源码在 `src/`：

| 文件 | 内容 |
|---|---|
| `Core.cs` | 数据模型、存储、SSH、远端脚本、调度计算 |
| `Ui.cs` | 主题配色、DPI 换算、按钮等控件工厂、自绘控件 |
| `MainForm.Layout.cs` | 主窗口界面搭建 |
| `MainForm.Logic.cs` | 主窗口行为：会话、表单、任务列表、执行、日志、托盘 |
| `Program.cs` | 入口、单实例、`--selftest` / `--layout` |

## 从旧版本升级

- `jobs.json` 完全兼容，直接覆盖 exe 即可。
- 如果之前用 `schtasks` 注册过登录自启任务 `CodexSchedulerApp`，建议删掉它，改用托盘菜单里的「开机自启动」（会带 `--tray` 静默启动）：

  ```powershell
  schtasks /delete /tn CodexSchedulerApp /f
  ```

  即使两个都保留，单实例保护也会保证只有一个进程在调度。

## 卸载

托盘菜单里取消「开机自启动」（或执行上面的 `schtasks /delete`），退出程序，然后删掉桌面快捷方式和本文件夹即可。
